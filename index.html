GroundStation: Ground Control Simulator

A real-time telemetry and command system for drones and aircraft. It runs as 4 services: 92-byte binary telemetry over UDP at 20Hz, plus an ordered TCP channel for 5 command types. I built a network-impairment proxy that simulates 0 to 100% packet loss and up to 2000ms of jitter, along with auto-reconnect. I also found and fixed 2 concurrency bugs using Playwright tests. Built with C++, TypeScript, and React.

Built with React, TypeScript, Node, Express, Socket.io, Prisma/MySQL, Docker, and GitHub Actions CI.
